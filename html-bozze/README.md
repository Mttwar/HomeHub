# Bozze HTML CasaHub

Apri `index.html` nel browser. Le bozze sono statiche, responsive e collegate tra loro.

Pagine incluse:

- `accesso.html`
- `index.html` — Dashboard
- `bollette.html`
- `spese.html`
- `segnalazioni.html`
- `messaggi.html`
- `calendario.html`

Tailwind viene caricato tramite CDN; `styles.css` contiene soltanto gli stili condivisi che completano le utility.

La selezione manuale del ruolo è stata rimossa: nel prodotto reale il profilo sarà assegnato all'account e verificato dal server.
